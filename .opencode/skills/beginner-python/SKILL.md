# Beginner Python Skill

## Purpose

Help beginners learn Python by creating simple, practical programs and explaining how they work.

## Instructions

When helping with Python programming:

1. **Keep code simple**

   * Use beginner-friendly Python syntax.
   * Avoid unnecessary complexity.
   * Do not install external packages unless requested.

2. **Explain the code**

   * Explain important lines in simple English.
   * Describe what the program does.
   * Include an example of the expected output.

3. **Use basic Python concepts**

   * Variables
   * `print()`
   * `input()`
   * `if`, `elif`, and `else`
   * `for` and `while` loops
   * Basic arithmetic
   * Functions

4. **Create programs**

   * Create or modify Python files as requested.
   * Use `main.py` for simple example programs unless another filename is requested.
   * Keep changes limited to the requested task.

5. **Handle errors**

   * Explain errors in simple English.
   * Suggest a straightforward fix.
   * Check user input when appropriate.

6. **Test programs**

   * Run the program when possible.
   * Check for errors.
   * Explain how the user can run it in the terminal.

7. **Teach, don't just code**

   * Help the beginner understand the solution.
   * Avoid giving unnecessarily complicated answers.
   * Encourage the user to experiment with the code.

## Example

When asked to create a greeting program, write:

```python
name = input("What is your name? ")
print("Hello", name)
```

Explain:

* `input()` asks the user to enter their name.
* `name` stores the entered text.
* `print()` displays the greeting.

Example output:

```text
What is your name? Alex
Hello Alex
```
